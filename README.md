# SCOUT — Semantic Coverage-Guided Testing of Autonomous Driving Systems

Anonymous artifact for external review. This repository contains the working
implementation used to produce the paper's experiments: semantic obligation
oracle construction, the CARLA scenario search harness, the simulator-state
semantic observer, the coverage engine, the matched-budget policy search, and
the aggregation/figure pipeline.

## Layout

- `research/harness/` — CARLA harness, observers (semantic / telemetry /
  coverage), coverage engine, 5-D search space, scenario generation and
  runtime controllers, leaderboard/PCLA agent bridge
- `research/experiments/EXP-018-nuscenes-oracle-inventory/` — oracle builder
  plus the constructed `v1.0-trainval` and `v1.0-mini` inventories
- `research/experiments/EXP-020-policy-comparison/` — matched-budget policy
  search (`policy_search.py`), aggregation (`aggregate_fse_search.py`),
  matrix launchers, and the base scenario specifications for all routes
- `research/scripts/` — per-map summary and figure generation
- `research/tests/` — unit tests (no CARLA required)

## Requirements

- Python 3.10 and `uv` (see `research/pyproject.toml`, `research/uv.lock`)
- CARLA 0.9.16 (Linux headless flags used for the campaign:
  `-RenderOffScreen -opengl -quality-level=Low -nosound`)
- InterFuser (PCLA) agent repository and checkpoints for the ADS under test
- nuScenes v1.0-trainval annotation metadata and map expansion files for
  oracle construction

## Reproduction

```bash
uv sync --directory research --python 3.10

research/.venv/bin/python -m pytest research/tests -q

# 1) build the semantic obligation oracle (deterministic; hash printed)
research/.venv/bin/python research/experiments/EXP-018-nuscenes-oracle-inventory/proof-of-concept/build_oracle_inventory.py \
  --dataset-root <nuscenes-root> --split v1.0-trainval --output-dir <out-dir>

# 2) matched-budget search, one worker per GPU (resumable)
bash research/experiments/EXP-020-policy-comparison/proof-of-concept/run_fse_multimap.sh A
bash research/experiments/EXP-020-policy-comparison/proof-of-concept/run_fse_multimap.sh B

# 3) aggregate and plot
research/.venv/bin/python research/experiments/EXP-020-policy-comparison/proof-of-concept/aggregate_fse_search.py \
  --search-root research/logs/fse_search
research/.venv/bin/python research/scripts/per_map_summary.py \
  --summary research/logs/fse_search/fse_summary.json --out-dir research/logs/fse_search
research/.venv/bin/python research/scripts/make_fse_figures.py \
  --search-root research/logs/fse_search --output-dir research/logs/fse_figures
```

No credentials, logs, or third-party model weights are included. Search outputs
are regenerated by steps (2)–(3).
