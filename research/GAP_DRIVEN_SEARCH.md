# Gap-driven semantic search (primary protocol)

This documents how the primary FSE campaign implements the review pipeline:

```
benign randomised seeds -> execute ADS -> scenario graphs -> semantic coverage
gaps -> select uncovered obligation -> select scenario type -> multi-parameter
search -> cover obligation -> next gap
```

## 1. Benign randomised seeds (review item 1)

Every route ships benign variants generated by `research/scripts/generate_benign_seeds.py`
(`<route>_benign_seed{0,1,2}.json` + a shared `benign_seeds.json` manifest). The
gap-driven launchers default to `_benign_seed0` (override with `SCOUT_BASE_SUFFIX`),
falling back to `<route>.json` when a benign variant is absent. All policies and
the no-adversary controls for a route start from the **same** spec, so the only
difference between arms is the search.

## 2. Coverage-gap -> scenario type (review item 2)

The semantic arm runs with `--hazard-search`, which wires
`research/harness/hazard_search.py` into `policy_search.py`:

- `ObligationScheduler` picks the highest-priority uncovered obligation
  (`_pick_target`) from the oracle inventory.
- `OBLIGATION_TEMPLATE_MAP` routes that obligation to a scenario template:

  | uncovered obligation | template |
  | --- | --- |
  | `crossing_path(pedestrian,ego)`, `jaywalking(pedestrian)`, `pedestrian_in_path`, `other: pedestrian` | `pedestrian_crossing` |
  | `braking(vehicle)`, `in_front_of(vehicle,ego)`, `same_lane(vehicle,ego)`, `other: ahead_or_waiting`, `other: start_stop_or_stationary` | `lead_vehicle_braking` |

## 3. Multi-parameter search per template (review item 3)

Each template owns a parameter space (`CROSSING_SPACE`, `LEAD_BRAKING_SPACE`).
The semantic fitness rewards witnessing the active obligation, tie-broken by its
constituent witnesses; the per-template elite resets when the target changes.
After `--hazard-stall-limit` unsuccessful attempts a target is deferred so the
loop moves on instead of stalling.

Lead-braking specs bake a route polyline from a live CARLA world, so the
launchers call `research/scripts/ensure_lead_braking_specs.sh` first (before any
worker starts). Without lead-braking specs, `braking(vehicle)`-type targets are
excluded and the method degenerates to pedestrian crossings only. Set
`SCOUT_ENSURE_LEAD_SPECS=0` to skip generation (e.g. specs already present).

## Launchers

`run_fse_matrix.sh`, `run_fse_multimap.sh`, and `run_fse_multimap_autovla.sh`
now run the gap-driven protocol by default: benign seed, `--hazard-search`,
engine metrics, paired controls. Output roots changed to keep them separate from
the earlier (non-gap) runs:

| campaign | output root |
| --- | --- |
| Town01 matrix | `research/logs/fse_search_gap_v1/seed-<seed>` |
| multi-map | `research/logs/fse_search_gap_v1/seed-<seed>` |
| AutoVLA | `research/logs/fse_search_autovla_gap_v1/seed-<seed>` |

The checkpoint fingerprint records `hazard_search`, so resuming a v1 output
directory with the gap protocol is rejected rather than silently mixed. Do not
combine rows across protocols.

## Frozen-seed gate (review item 4)

Before a campaign, run one identical benign seed without search:

```bash
bash research/scripts/validate_frozen_seed.sh \
  research/experiments/EXP-020-policy-comparison/artifacts/base_specs/town01_spawn0_goal82_benign_seed0.json \
  20 2000 0
```

Set `SCOUT_AGENT_KIND=autovla` (plus `SCOUT_AGENT_REPO`/`SCOUT_AGENT_CONFIG`) to
run the gate for AutoVLA; the default is the InterFuser/PCLA path. If the
collision rate on a benign frozen seed is still high, debug the ADS/CARLA bridge
before attributing anything to the search.

## Known limitations

- Selection and elites are **per template**, not per obligation, and maps/routes
  are independent arms (no shared cross-map scheduler).
- `ObligationScheduler.select()` is the single live selection path (called by
  `policy_search._pick_target`) and is given the real covered set, so a credited
  target advances; `observe(set())` is no longer used on the campaign path.
- Primitive grounding for the mapped simulator predicates remains documented
  geometric proxies, not manually validated labels.
